TraceFold Windows 离线测试版 0.1.0
=================================

一、适用环境

- Windows 10/11 x64
- Python 3.12 x64（安装时需能运行 py -3.12）
- FFmpeg 与 FFprobe（需加入 PATH）
- Microsoft Edge

本包不包含上述软件。安装 TraceFold 测试环境时只读取包内 wheelhouse，
不会访问网络；测试电脑不需要 Node.js。

二、首次使用

1. 对照随 ZIP 提供的 .sha256 文件校验 ZIP 的 SHA-256。
2. 将 ZIP 完整解压到一个新的、可写的目录，不要直接在压缩包内运行。
3. 双击“安装测试环境.cmd”，等待提示安装成功。此步骤通常只需执行一次，
   也可以安全地重复执行。
4. 双击“启动 TraceFold.cmd”。程序会用 Edge 应用模式打开独立窗口。
5. 关闭该 Edge 窗口后，本次 TraceFold 服务会一并退出。

三、目录用途

- data/inbox：待扫描、待入库的图片和视频。
- data/library：正式入库后的媒体文件。
- data/work：合并音视频等前置处理的临时工作目录。
- data/media.sqlite3：标签、作者、系列、显示名称等数据库信息（首次安装生成）。
- runtime/logs：安装、启动和运行日志；遇到故障时先查看这里。
- runtime/edge-profile：此测试版专用的 Edge 配置。

请定期自行备份整个 data 目录。本测试版用于功能验收，不是生产备份目标。

四、升级与注意事项

- 新版本应解压到新的版本目录，不要覆盖旧目录。
- 程序不会自动覆盖或迁移旧版 data。只有在确认版本兼容并自行备份后，
  才由用户明确决定是否复制旧数据。
- 端口 127.0.0.1:8100 被占用时，启动器会中止，不会结束其他程序。
- 安装失败时请确认 Python 恰为 3.12 x64，并确认 FFmpeg、FFprobe、Edge 可用。
