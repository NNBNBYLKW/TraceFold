# TraceFold 使用指南

本指南面向 **v4.0.0-stage5cc 预发布版**。适用系统为 **Windows 11 24H2（build 26100）或更新版本，x64**。

[返回项目首页](../README.md) · [常见问题与排障](troubleshooting.md) · [获取支持](../SUPPORT.md)

## 1. 下载并启动

[下载产品 ZIP（约 226 MB）](https://github.com/NNBNBYLKW/TraceFold/releases/download/v4.0.0-stage5cc/TraceFold-MediaDesktop-Stage5C-C-win-x64.zip)，完整解压到本地文件夹，再运行解压目录内的 **TraceFold.Media.exe**。保留所有随包文件和子目录，不要只复制 exe，也不要直接在压缩包中运行。

普通使用不需要 UI 验收工具包，也不需要 GitHub 的 Source code 压缩包。产品包包含 .NET、Windows App SDK 运行组件及 FFmpeg，通常无需另装。如遇启动问题，请先看 [排障说明](troubleshooting.md)。

## 2. 准备三个目录

建议先用少量素材副本熟悉流程，把独立原始备份放在这三个目录之外。打开 **设置 → 文件夹与扫描**，选择或填写：

| 设置项 | 用途 | 示例 |
| --- | --- | --- |
| 待入库目录 | 放置准备整理、尚未正式入库的素材副本 | D:\TraceFoldDemo\Inbox |
| 正式文件库目录 | 存放已确认入库的正式媒体文件 | D:\TraceFoldDemo\Library |
| 工作目录 | 保存前置处理所需的工作文件 | D:\TraceFoldDemo\Work |

三个目录必须不同，且**不能互相包含**。示例中三个文件夹是同级目录；不要把 Library 或 Work 放进 Inbox，也不要把其中一个目录设置为另外两个目录的父目录。

点击 **保存设置**，确认出现“设置已保存”。目录设置需要这一步保存；它与后面的资料自动保存不同。自动扫描默认关闭，首次使用可先保持关闭并手动刷新。设置页也可查看前置处理工具是否可用。

## 3. 扫描照片或视频

1. 将普通照片或视频的副本放进待入库目录，等待复制完成。
2. 打开 **待入库**，点击 **立即刷新**。
3. 如果显示“等待文件稳定”，等待文件不再写入后稍候再刷新。
4. 选中一项素材后查看右侧资料，核对预览及文件信息；若面板未显示，再点击 **查看资料**。右侧面板内容较长时可向下滚动。

普通照片或视频可在状态允许时直接正式入库。扫描只是发现素材，并不等于入库。

### 同名 MP4 + M4A 的前置处理

如果视频和音轨分开保存，在同一待入库目录放置相同主文件名的两个文件，例如：

~~~text
paired.mp4
paired.m4a
~~~

扫描后它们归并为一个配对项目，M4A 不另列成一条库项目。当状态显示 **需要前置处理** 时：

1. 选择配对视频，在资料面板中点击 **开始前置处理**。
2. 等待排队和处理完成，确认状态允许入库。
3. 查看处理结果，再点击 **正式入库**。

**处理完成不等于正式入库。** 仅运行前置处理不会立即清理原 MP4/M4A；仍需完成下一步入库。

## 4. 确认正式入库

在待入库区填写所需资料，核对选中对象后，点击 **正式入库**。如果出现冲突比较窗口，请先比较新旧素材，再按界面决定跳过、保留两者或替换选定目标；关闭窗口或按 Esc 不代表确认替换。

入库完成后到 **正式文件库** 查找素材，核对预览和资料；也可使用 **打开所在目录** 查看正式文件。

### 源文件会怎样处理？

成功入库会将素材提交到正式文件库并登记资料，随后按策略清理待入库源文件；配对处理成功入库后，原 MP4、原 M4A 及处理工作输出也会清理。**待入库目录不是永久备份目录，入库也不是“多复制一份并永远保留源文件”。**

失败、中断或源/目标变化时有受控恢复与清理机制，不应把源文件暂时还在视为需要手动删除。遇到失败或清理提示，先记录完整提示并参照 [排障说明](troubleshooting.md)，不要自行删除数据库或工作目录来重置状态。

## 5. 编辑资料并确认保存

进入 **正式文件库**，只选中一项素材后查看右侧资料；若面板未显示，再点击 **查看资料**：

- 修改 **显示名称**：改变软件中的名称，实际文件名、文件内容和位置保持不变。
- 添加 **作者、系列或内容标签**：输入名称后按 **Enter**，确认它成为已添加的词条；仅把文字留在输入框中不算完成添加。
- 资料采用**自动保存**，没有独立的“保存资料 / 应用”按钮。编辑后稍候，切换到另一项再切回，核对值是否读回，并留意状态提示。

多选时会进入批量操作语境；初次使用先完成单条编辑。筛选面板中的 **应用** 用于应用筛选条件，不是保存资料。

## 6. 搜索文件并使用词表

**正式文件库** 顶部可搜索文件名或显示名称。打开 **筛选**，选择作者、系列或内容标签等条件，再点击筛选面板的 **应用**。例如，在 **作者（全部包含）** 中选一个已添加到素材的作者，应能筛出相应素材；结束后使用 **全部清除** 恢复。

**词表管理** 用于查看和维护作者、系列、内容标签。选择类型、搜索词条，选中后查看右侧详情；窄窗口未展开时点击 **查看详情**，可查看待入库和正式库的引用计数。引用计数反映资料关联，词条并不是媒体文件夹。

可用下面的方法确认关联是否正确：

1. 在正式库某张照片上添加一个作者并按 Enter。
2. 切换素材后再切回，确认该作者仍在。
3. 在词表管理中查看这个作者的引用。
4. 回正式库按该作者筛选，确认目标照片出现。

## 7. 后续使用与反馈

先确认少量副本的扫描、入库、资料读回和搜索符合预期，再逐步使用更多素材。保留正式库文件及相关应用数据的备份；不要把工作目录中的文件当作已正式入库的唯一副本。

遇到问题请查看 [常见问题与排障](troubleshooting.md)，需要反馈时参照 [支持说明](../SUPPORT.md)。版本的已验证范围及限制统一见 [版本状态](../README.md#版本状态)。
