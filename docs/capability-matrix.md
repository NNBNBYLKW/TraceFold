# TraceFold 当前发布能力矩阵

[English](capability-matrix.en.md) | [返回 README](../README.md)

本文只描述当前公开预发布 `v4.0.0-stage5cc` 的产品能力。公开产品由源码身份 `01264b7a086aebfcfa2f546d294def5076113e3e` 构建；默认分支源码和未发布构建不代表当前产品能力。

## 已发布范围

| 能力 | 当前公开预发布 | 说明 |
| --- | --- | --- |
| Windows 桌面媒体整理 | 已提供 | Windows 11 24H2（build 26100）或更新版本，x64。 |
| 待入库照片和普通视频预览 | 已提供 | 需要使用待入库目录、正式文件库目录和工作目录。 |
| 同名 MP4/M4A 配对与前置处理 | 已提供 | 处理完成不等于正式入库，仍须确认入库。 |
| 显示名称、作者、系列和内容标签 | 已提供 | 资料自动保存；显示名称与磁盘文件名分离。 |
| 搜索、筛选和词表引用 | 已提供 | 可按文件名、显示名称、作者、系列和内容标签使用已有流程。 |
| 冲突比较与处置 | 已提供 | 可跳过、保留两者或按界面流程替换。 |
| 本地文件工作流 | 已提供 | 默认文档没有要求先配置云服务或在线账号。 |
| 自带运行组件 | 已提供 | 产品包包含 .NET、Windows App SDK 及 FFmpeg/FFprobe。 |

## 已知范围与限制

| 项目 | 当前状态 | 对用户/AI 的含义 |
| --- | --- | --- |
| Release 稳定性 | 预发布，非稳定版 | 不要把当前版本描述为正式稳定发布。 |
| UI 自动综合验收 | 7 通过、5 失败、2 阻塞 | 失败和阻塞没有被人工通过改写为全绿。 |
| 视觉矩阵 | 未完成完整覆盖 | 不宣称全部明暗主题和窗口尺寸组合已通过。 |
| 干净虚拟机 | `NotRun` | 不宣称已完成干净系统兼容性验收。 |
| 项目许可证 | 未声明 | 不把项目授权状态写成已确认，也不把第三方许可证当成项目许可证。 |

## 当前公开产品不包含

以下内容不是 `v4.0.0-stage5cc` 的已发布能力，不能写成“现在可用”：

- 供第三方直接控制桌面应用的公开 API、CLI 或 MCP 集成。
- PDF、EPUB、漫画阅读或独立音乐文件入库与音乐播放器/音乐库；现有普通视频及其音轨不等于独立音乐库。
- 多资料空间与多实例工作流。
- OCR、音频转录、人物识别匹配或自动标签。
- 正式文件库缺失文件隐藏与手动移除失效记录；这些不属于当前 Release。
- UI 验收工具包作为普通用户的运行入口。

计划或研究材料不等于已实施功能。若后续版本真的加入上述能力，应同步更新本矩阵、公开说明、版本身份和实际验收证据。
