# TraceFold Media Desktop Stage 5B 人工验收指南

## 验收前准备

使用本次交付的 `TraceFold-MediaDesktop-Stage5B-win-x64.zip`，解压到普通本地目录。准备一个独立测试目录作为待入库目录、一个正式文件库目录和一个工作目录；不要复用真实资料库。待入库目录至少放入 4 张图片和 2 个视频，其中一组为同名 `.mp4`/`.m4a`。正式入库后，为测试资产准备：至少 3 位作者、2 个系列、4 个内容标签，且有部分资产故意缺少作者、系列或标签。

在开始批量编辑前，用 PowerShell 记录正式文件事实：

```powershell
Get-ChildItem '正式文件库路径' -File -Recurse |
    Where-Object FullName -NotMatch '[\\/]\.tracefold[\\/]' |
    Get-FileHash -Algorithm SHA256 |
    Export-Csv .\stage5b-files-before.csv -NoTypeInformation -Encoding UTF8
```

每项验收都记录“通过/失败”、操作时间、所选资产和截图。失败时不要反复覆盖现场；先保存下方列出的证据。

## 17 项人工检查

### 1. 正式库测试资料覆盖

- 设置：确认正式库同时包含图片、视频、多作者、多标签、不同系列，以及缺少作者/系列/标签的资产。
- 预期：卡片数、媒体类型和右侧资料详情与准备数据一致；单项预览仍可用。
- 失败证据：正式库全景截图、问题资产右侧详情截图、日志目录中对应时间段的日志。

### 2. 多维筛选严格取交集

- 设置：同时选择媒体类型、作者、系列、标签、缺失资料和显示名称状态中的多个条件并应用。
- 预期：只显示同时满足全部条件的资产，不出现仅满足部分条件的资产。
- 失败证据：筛选条件标签、结果卡片和问题资产资料详情的同屏截图。

### 3. 两位作者/两个标签表示“全部包含”

- 设置：选择作者甲和作者乙，再选择标签甲和标签乙；准备一个只含其中一项的对照资产。
- 预期：结果必须同时包含两位作者和两个标签；语义是“全部”，不是“任意一个”。
- 失败证据：四个筛选词项、错误出现的对照资产及其详情截图。

### 4. 筛选草稿、标签和数量

- 设置：依次测试应用、取消、逐项移除条件标签和“全部清除”。
- 预期：取消不改变已应用条件；逐项移除只去掉对应条件；全部清除恢复默认结果；标签和数量同步。
- 失败证据：操作前后截图，并标注哪一个条件或数量没有同步。

### 5. 搜索/筛选清空选择，排序保留选择

- 设置：多选至少 2 项后改变搜索文字或应用筛选；重新多选后只改变排序字段或方向。
- 预期：搜索或筛选变化会清空选择并提示；只改变排序时选择仍保留，顺序随排序更新。
- 失败证据：变化前后的选择数、状态提示和所选卡片截图。

### 6. Windows 式多选操作

- 设置：分别使用单击、`Ctrl`、`Shift`、`Ctrl+A` 和 `Esc`。
- 预期：增量选择、连续范围、全选和取消选择符合资源管理器习惯；右侧多选摘要的总数、图片数和视频数正确。
- 失败证据：按键方式、预期范围、实际高亮卡片和摘要截图。

### 7. 资料与命名在一个对话框联动

- 设置：打开“批量编辑”，添加或替换作者/系列/标签，同时添加 `{authors}`、`{series}` 或 `{tags}` 命名模板。
- 预期：命名预览立即使用拟议中的新资料，而不是数据库中的旧资料；关闭或取消不落库。
- 失败证据：资料页输入、命名页规则和同一资产预览截图。

### 8. 八类命名规则

- 设置：逐一验证前缀、后缀、普通替换、删除文本、删除括号内容、大小写、编号和资料模板。
- 预期：每条规则只产生对应变化；编号按当前选择快照的明确顺序生成；扩展名不进入显示名称。
- 失败证据：规则参数、规则顺序、实际/当前/生成三列预览截图。

### 9. 名称来源切换

- 设置：为资产先设置自定义显示名称，再在“实际文件名”和“当前显示名称”之间切换。
- 预期：预览源随选择切换；实际文件名来源会去掉最后一个扩展名；磁盘文件名不变。
- 失败证据：来源选择、三列预览以及资源管理器中的实际文件名截图。

### 10. 规则顺序和启用状态

- 设置：建立至少 3 条有顺序依赖的规则，上移、下移并逐条停用/启用，然后提交。
- 预期：每次操作都实时重算；最终落库显示名称与提交前最后一次预览逐项一致。
- 失败证据：提交前规则列表与预览、提交后正式库卡片截图。

### 11. 命名预设持久化且不自动运行

- 设置：保存新预设，制造同名冲突并确认覆盖，加载、删除另一个预设；重启软件。
- 预期：同名必须显式覆盖；重启后保留的预设仍存在；加载预设只填充草稿，不自动提交；删除项不再出现。
- 失败证据：预设列表、覆盖提示、重启前后截图和日志。

### 12. 命名错误阻止整批且保留输入

- 设置：分别制造空名称、超过长度限制的名称、缺少 `{authors}`/`{series}`/`{tags}` 所需资料。
- 预期：应用按钮不可用或提交被拒绝；整个批次零修改；错误定位到首项问题；切换选项卡后输入和规则仍保留。
- 失败证据：错误信息、规则与预览、关闭对话框后的正式库截图。

### 13. 重复显示名称只警告

- 设置：令批次内两项生成相同显示名称，或生成一个与未选资产相同的显示名称。
- 预期：警告数增加且明确展示，但仍允许提交；提交不修改物理文件名。
- 失败证据：警告预览、应用按钮状态和提交结果截图。

### 14. 版本冲突保证整批零修改

- 设置：打开批量对话框并保留草稿，在另一次单项编辑中修改其中一个选中资产，再回到批量对话框提交。
- 预期：提示“选择中的资料已变化，请刷新后重试”；所有选中资产均未应用该批草稿，输入仍保留。
- 失败证据：冲突提示、提交前草稿、所有选中资产提交后的详情截图。

### 15. 一次性原子撤销

- 设置：成功提交一个同时修改资料和显示名称的批次，点击顶部撤销；随后再做一批修改，并单独编辑其中一个相关资产后尝试旧撤销。
- 预期：第一次撤销对全部资产同时恢复资料和显示名称；不能只恢复一部分；相关单项编辑使旧撤销失效；没有第二层撤销历史。
- 失败证据：提交前、提交后、撤销后各资产详情，以及撤销横幅状态截图。

### 16. 物理文件事实始终不变

- 设置：完成筛选、批量编辑、失败提交、成功提交和撤销后，再导出文件哈希；同时在资源管理器检查位置。
- 预期：实际文件名、扩展名、相对路径、文件大小和 SHA-256 全部与验收前一致。
- 失败证据：运行以下比较并保存输出；任何差异都视为阻断问题。

```powershell
Get-ChildItem '正式文件库路径' -File -Recurse |
    Where-Object FullName -NotMatch '[\\/]\.tracefold[\\/]' |
    Get-FileHash -Algorithm SHA256 |
    Export-Csv .\stage5b-files-after.csv -NoTypeInformation -Encoding UTF8
Compare-Object (Import-Csv .\stage5b-files-before.csv) (Import-Csv .\stage5b-files-after.csv) -Property Path,Hash
```

### 17. 离线包与进程清理

- 设置：断开网络或阻止联网，在受限 `PATH` 下从解压目录启动软件，完成核心筛选、批量编辑和撤销后关闭窗口。
- 预期：软件以独立原生窗口启动，不打开 Edge/Chrome，不依赖浏览器；第二次启动会回到单实例；退出后不存在 `TraceFold.Media.exe` 或包内 `ffmpeg.exe` 残留进程。
- 失败证据：任务管理器截图、进程路径、错误窗口、包内 `logs` 目录以及是否出现浏览器进程。

## 验收结论

只有 17 项全部通过、自动包级烟雾通过且第 16 项比较无差异，才能标记 Stage 5B 本机验收通过。当前没有干净 Windows 11 x64 虚拟机或另一台全新机器；本机结果不能替代无 SDK、无开发工具、无既有运行状态的干净系统发布门槛，该项必须继续标记为待验证。
