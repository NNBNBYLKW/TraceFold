# TraceFold Media Desktop Stage 5C-B 系统诊断测试指南

## 测试对象

- 检查点：`5C-B`
- 解压目录：`TraceFold-MediaDesktop-Stage5C-B-win-x64`
- 启动文件：`TraceFold.Media.exe`
- 本轮只验证独立 Windows 桌面程序；不需要联网，也不应打开浏览器。
- 正式验证前，请备份仍需保留的测试资料。受控故障项只在复制出的测试包和测试目录中执行。

## 自动包探针

运行发布脚本后，由烟雾测试脚本执行 `stage5cb-diagnostics`。预期在 60 秒内退出，结果文件为 `stage5cb-diagnostics-probe-result.json`，其中除 `PackagedEnvironmentHealthy` 等布尔值及空的 `ErrorCode` 外不包含路径、文件名、资料、哈希或标识符。所有布尔证明项都应为 `true`，`ErrorCode` 应为 `null`。

## 人工验收清单

1. 启动后进入“设置”。默认选中“文件夹与扫描”，原有三个目录、自动扫描状态及前置处理工具状态均可见。

2. 只使用键盘在“文件夹与扫描”和“系统诊断”之间切换。`Tab`、方向键、`Enter`、`Space` 均按原生 Windows 控件习惯工作；屏幕阅读器可读出标签页、重新检查、复制摘要和问题操作的中文名称。

3. 第一次进入“系统诊断”时自动开始检查，页面显示“正在检查”。离开再返回不会自动重复运行；需要再次检查时使用“重新检查”。

4. 检查完成后显示总体状态和最近检查时间。分组顺序固定为：目录与磁盘、数据库、前置处理工具、后台状态、日志与运行环境。每个状态同时有图标和文字。

5. 点击“重新检查”时，上一份完整结果继续显示，直到新结果整体替换；检查期间重复点击不会排入第二次刷新。

6. 目录与磁盘组显示当前已保存的待入库、正式文件库和工作目录及其容量结论。尚未点击“保存设置”的界面草稿不能被当作当前有效目录。

7. 前置处理工具组分别显示 FFmpeg 与 FFprobe 的可用状态和版本，不应把两者合并成一个模糊结果。

8. 数据库组显示数据库可打开、已应用迁移与程序迁移一致，并且 SQLite `quick_check` 为 `ok`。

9. 后台状态组只显示排队、运行、中断、失败、等待恢复或清理的数量，不显示任务 ID、文件名、路径或资料内容。

10. 将完整程序包复制为单独的故障测试副本。在副本中仅移走一个测试目录，或仅临时移走 `tools\ffmpeg\ffmpeg.exe` / `ffprobe.exe` 后重新检查。预期只有对应诊断项变为“需要留意”或“不可用”，普通文件浏览、标签编辑及不依赖该工具的文件管理仍可使用。验证后把文件恢复，不在正式测试包上保留故障。

11. 问题项展开显示结论、影响、处理建议和稳定错误代码；同一问题不会连续弹出模态对话框阻断操作。

12. 对目录问题选择“前往文件夹设置”。预期自动切回“文件夹与扫描”，并准确聚焦对应的待入库、正式文件库或工作目录一行。

13. 选择“打开日志目录”。预期只打开程序注册的应用日志根目录，不得根据诊断结果中的任意路径打开其他位置。

14. 选择“复制摘要”，粘贴到纯文本编辑器检查。摘要不得包含 Windows 用户名、绝对路径、媒体文件名、作者/系列/标签等资料、文件哈希、数据库或任务 ID；允许包含版本、数量、状态和稳定错误代码。

15. 在检查前后分别记录待入库条目数、正式文件数、标签资料、设置值和后台状态数量。运行诊断与复制摘要后，这些业务和媒体事实应完全一致。

16. 关闭程序后，在三个已保存目录中搜索 `.tracefold-write-probe-*.tmp`，预期为零；任务管理器中不应残留该测试包的 `TraceFold.Media.exe`、`ffmpeg.exe` 或 `ffprobe.exe` 子进程。

17. 断开网络，并在仅保留 Windows `System32` 的受限 `PATH` 环境下启动。预期 15 秒内出现 TraceFold 原生独立窗口，不打开 Edge、Chrome 或其他浏览器；第二次启动会转到现有实例并退出。

18. 干净 Windows 11 x64 机器或虚拟机验证：**未执行**。当前没有第二台 Windows 11 x64 机器或虚拟机，因此不得将此项标记为通过；后续具备环境时需重新执行安装、离线启动、原生窗口和完整诊断检查。

## 通过条件

自动包探针全部证明项为 `true`，人工清单第 1—17 项符合预期，第 18 项保持“未执行”并明确记录环境限制。任何诊断导致业务数据、设置、后台状态或媒体文件变化，或留下临时文件/子进程，均判定本检查点不通过。
