# TraceFold Media Desktop Stage 5A 人工测试指南

本指南只用于已解压的 Stage 5A 离线 Windows x64 包。测试期间保持网络断开；所有文件均为复制件，且所有目录必须位于本轮新建的隔离根目录，不能使用个人待入库目录或正式媒体库。

## 一、准备

1. 解压 `TraceFold-MediaDesktop-Stage5A-win-x64.zip` 到一个无空格、可写的位置，例如 `T:\TraceFold-Stage5A-Package`。
2. 新建测试根目录 `T:\TraceFold-Stage5A-Manual`，并创建以下精确目录：

   ```text
   T:\TraceFold-Stage5A-Manual\data
   T:\TraceFold-Stage5A-Manual\inbox
   T:\TraceFold-Stage5A-Manual\library
   T:\TraceFold-Stage5A-Manual\work
   T:\TraceFold-Stage5A-Manual\fixtures
   T:\TraceFold-Stage5A-Manual\screenshots
   ```

3. 在 `fixtures` 中准备下列文件。图片必须内容不同；`ordinary.mp4` 可由 `paired.mp4` 复制并改名；`photo-copy.jpg` 必须是 `photo.jpg` 的内容相同副本，用于产生内容冲突。

   ```text
   photo.jpg                 （图片 1）
   image-b.jpg               （图片 2，内容不同）
   ordinary.mp4              （普通视频）
   paired.mp4                （同名媒体对的视频）
   paired.m4a                （同名媒体对的音频）
   photo-copy.jpg            （photo.jpg 的相同内容副本，仅用于冲突项）
   ```

4. 在网络断开时，从解压目录启动原生程序；不要从源码目录启动：

   ```powershell
   $env:TRACEFOLD_MEDIA_DESKTOP_DATA_ROOT = 'T:\TraceFold-Stage5A-Manual\data'
   .\TraceFold.Media.exe
   ```

5. 在“设置”中依次选择并保存以下目录：待入库 `T:\TraceFold-Stage5A-Manual\inbox`、正式文件库 `T:\TraceFold-Stage5A-Manual\library`、工作目录 `T:\TraceFold-Stage5A-Manual\work`；自动扫描保持关闭。每项截图以 `01-` 至 `13-` 开头保存在 `screenshots`。

每一个项目都必须填写：`通过 / 不通过`、`观察到的消息`、`截图文件名`。未通过时保留源文件和截图，不要手工删除产品内部目录。
