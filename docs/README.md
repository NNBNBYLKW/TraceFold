# TraceFold 使用文档

TraceFold 是 Windows 本地媒体整理工具，提供待入库处理、正式文件库和标签分类。

## 开始使用

1. [下载当前产品预发布版](https://github.com/NNBNBYLKW/TraceFold/releases/tag/v4.0.0-stage5cc)：普通使用选择 `TraceFold-MediaDesktop-Stage5C-C-win-x64.zip`。
2. [快速开始](getting-started.md)：完整解压、启动、设置目录、处理与正式入库。
3. [常见问题](troubleshooting.md)：无法启动、目录冲突、扫描、保存、版本与日志。
4. [支持与反馈](../SUPPORT.md)：报告问题或提出建议。

当前为 `v4.0.0-stage5cc` 预发布版；适用系统和验证边界见 [Release 说明](https://github.com/NNBNBYLKW/TraceFold/releases/tag/v4.0.0-stage5cc)。[返回项目首页](../README.md)。
